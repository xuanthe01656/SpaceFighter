🚀 Quick Start (3 Steps)
Step 1. Configure Environments
Create a .env file in client/ with your VITE_SOCKET_URL and VITE_FIREBASE_* keys.
Create a .env file in server/ with PORT=3000.

Step 2. Install & Start Backend
cd server && npm install && npm start
(Server starts on http://localhost:3000)

Step 3. Install & Start Frontend (New Terminal)
cd client && npm install && npm run dev
(App starts on http://localhost:5173)

Open your browser, login with Google, and play!
